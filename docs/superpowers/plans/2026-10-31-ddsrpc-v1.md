# ddsrpc 第一版实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在固定版本的 Transport/AsyncTask 之上，交付 `ddsrpcgen`、类型化 Service/Client 生成代码和运行时，使 `.idl` 中声明的 SLOT/SIGNAL/PROP 能通过 DDS 请求-响应与发布-订阅工作，并在断线重连后自动刷新属性。

**Architecture:** 手写 lexer/递归下降 parser 生成 AST，语义层解析类型、分配 op/event id 并计算每个 IDL 的 schema hash，再由 Types/Service/Client 三个 emitter 生成普通 C++ 门面。运行时只保留公共信封、错误、任务组、ServiceBase/ClientBase；生成的 client 直接轮询 `DdsTransport::CurrentLinkState()`，不做 LinkState 抽象。所有验收测试跑在 WSL + FakeDdsProvider 上。

**Tech Stack:** C++17、Qt 5.12 Core/Network/SerialPort、Transport 0.6.0、AsyncTask master、CMake 3.16、GoogleTest（使用 Transport vendored 副本）、qmake 示例。

## Global Constraints

- 验收环境固定为 Ubuntu 20.04 WSL；构建和测试必须在 WSL 内执行，不依赖 Windows 原生 Transport 构建。
- Boost >= 1.89.0 安装到 `/usr/local`；AsyncTask d231d64 依赖 `boost/fiber/waker.hpp`，1.72 不满足。
- 依赖 commit 固定：`third_party/AsyncTask` = `d231d64`，`third_party/Transport` = `1c79cd5`。
- Transport 编译时必须把 `ASYNCTASK_DIR` 指向仓库根的 `third_party/AsyncTask`；不要初始化 Transport 自带的旧 AsyncTask 子模块。
- 输入文件扩展名 `.idl`；导入语法固定为 `IMPORT "path.idl";`；C++ 指令（`#include` 等）单行透传。
- `.idl` 支持范围仅限：`IMPORT`、`POD`、顶层/类内 `ENUM`、`class`、`PROP`、`SIGNAL`、`SLOT`。
- 明确拒绝：`MODEL`、`CLASS`、`FLAG`、`USE_ENUM`、`PERSISTED`、花括号 POD、`#HEADER`、`#FOOTER`。
- 同一个 IDL 文件对应一个 schema hash；不使用 instance UUID/session ID。
- 生成 Client 构造参数直接是 `transport::DdsNode& node, transport::DdsTransport& transport`；生成代码直接调用 `transport_.CurrentLinkState()`，不增加 LinkStateSource/adapter。
- Client `prepare/start` 不等待服务上线；`ready=false` 直到首次 schema 握手和属性快照成功。
- 链路由非 Up 回到 Up 时，重新订阅事件 topic、重置属性 revision 基线、自动全量刷新 PROP、恢复 `ready`。
- 服务端每个请求在独立 `Coro::makeTask` 中执行，无并发上限；`stop()` 取消并汇合在途任务。
- 客户端向服务端上行只允许 SLOT；客户端不是事件 publisher。
- 生成 API 使用 `Coro::Result<T>`（默认 `std::error_code`）；框架错误使用 `ddsrpc::RpcErrc` error category；Transport 错误原样透传。
- CMake 为主构建；qmake 仅提供一个消费示例。
- 所有生成输出必须确定性（相同输入相同字节）、UTF-8、LF、带 include guard，并先写临时文件再原子替换。
- 所有生成文件默认会被下一次生成覆盖；需要长期手改时，在生成器/模板中修改，或停止重新生成。

```bash
#!/usr/bin/env bash
set -euo pipefail
ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
wsl_path_root="$(wslpath -a "$ROOT" 2>/dev/null || printf '%s' "$ROOT")"

  -B /tmp/ddsrpc-transport-spike \
  -DASYNCTASK_DIR="$wsl_path_root/third_party/AsyncTask" \
  -DTRANSPORT_BUILD_TESTS=OFF \
  -DTRANSPORT_BUILD_PERF=OFF \
  -DCMAKE_BUILD_TYPE=Debug
cmake --build /tmp/ddsrpc-transport-spike -j"$(nproc)"
printf 'Transport build spike OK\n'
```

```cpp
#include <gtest/gtest.h>

#include <QString>

#include "diagnostic.h"
#include "lexer.h"

using ddsrpcgen::Diagnostics;
using ddsrpcgen::Lexer;
using ddsrpcgen::TokenKind;

TEST(LexerTest, TokenizesDirectivesImportsAndClassBody) {
  const QString source = QStringLiteral(
      "#include <QString>\n"
      "IMPORT \"common.idl\";\n"
      "class Foo {\n"
      "  PROP(int count = 1)\n"
      "};\n");
  Diagnostics diagnostics;
  Lexer lexer(QStringLiteral("test.idl"), source, diagnostics);
  const auto tokens = lexer.Scan();

  ASSERT_FALSE(diagnostics.HasErrors()) << diagnostics.Format().toStdString();
  ASSERT_GE(tokens.size(), 6);
  EXPECT_EQ(tokens[0].kind, TokenKind::Preprocessor);
  EXPECT_EQ(tokens[0].text, QStringLiteral("#include <QString>"));
  EXPECT_EQ(tokens[1].kind, TokenKind::Identifier);
  EXPECT_EQ(tokens[1].text, QStringLiteral("IMPORT"));
  EXPECT_EQ(tokens[2].kind, TokenKind::String);
  EXPECT_EQ(tokens[2].text, QStringLiteral("common.idl"));
  EXPECT_EQ(tokens[3].kind, TokenKind::Semicolon);
  EXPECT_EQ(tokens[4].kind, TokenKind::Identifier);
  EXPECT_EQ(tokens[4].text, QStringLiteral("class"));
}

TEST(LexerTest, TracksLineAndColumnAndSkipsComments) {
  const QString source = QStringLiteral(
      "// a comment\n"
      "class /* block */ Foo {\n"
      "};\n");
  Diagnostics diagnostics;
  Lexer lexer(QStringLiteral("test.idl"), source, diagnostics);
  const auto tokens = lexer.Scan();

  ASSERT_FALSE(diagnostics.HasErrors());
  ASSERT_GE(tokens.size(), 3);
  EXPECT_EQ(tokens[0].loc.line, 2);
  EXPECT_EQ(tokens[0].loc.column, 1);
  EXPECT_EQ(tokens[0].text, QStringLiteral("class"));
  EXPECT_EQ(tokens[1].loc.line, 2);
  EXPECT_EQ(tokens[1].text, QStringLiteral("Foo"));
}

TEST(LexerTest, TokenizesNestedTemplatesAndReferences) {
  const QString source = QStringLiteral(
      "SLOT(const QMap<QString, QList<Point>> &values)\n");
  Diagnostics diagnostics;
  Lexer lexer(QStringLiteral("test.idl"), source, diagnostics);
  const auto tokens = lexer.Scan();

  ASSERT_FALSE(diagnostics.HasErrors()) << diagnostics.Format().toStdString();
  int less_count = 0;
  int greater_count = 0;
  bool saw_ampersand = false;
  for (const auto& token : tokens) {
    less_count += token.kind == TokenKind::Less ? 1 : 0;
    greater_count += token.kind == TokenKind::Greater ? 1 : 0;
    saw_ampersand = saw_ampersand || token.kind == TokenKind::Ampersand;
  }
  EXPECT_EQ(less_count, 2);
  EXPECT_EQ(greater_count, 2);
  EXPECT_TRUE(saw_ampersand);
}

TEST(LexerTest, ReportsUnterminatedStringAtItsStart) {
  Diagnostics diagnostics;
  Lexer lexer(QStringLiteral("bad.idl"), QStringLiteral("IMPORT \"x.idl;\n"), diagnostics);
  (void)lexer.Scan();

  ASSERT_TRUE(diagnostics.HasErrors());
  ASSERT_EQ(diagnostics.All().size(), 1) << diagnostics.Format().toStdString();
  EXPECT_EQ(diagnostics.All()[0].file, QStringLiteral("bad.idl"));
  EXPECT_EQ(diagnostics.All()[0].loc.line, 1);
  EXPECT_EQ(diagnostics.All()[0].loc.column, 8);
  EXPECT_NE(diagnostics.All()[0].message.indexOf(QStringLiteral("unterminated string")), -1);
  EXPECT_NE(diagnostics.Format().indexOf(QStringLiteral("bad.idl")), -1);
}

TEST(LexerTest, ReportsStringCrossingNewlineAndRecovers) {
```

```cpp
namespace ddsrpcgen {

struct SourceLocation {

  int column = 1;
  int offset = 0;

struct Diagnostic {
  QString file;
  SourceLocation loc;
```

```cpp
  QString source_;
```

`lexer.cpp` 实现要点（完整实现，按下面分支处理）：

```cpp
#include "lexer.h"

#include <QChar>

namespace ddsrpcgen {
namespace {
[[nodiscard]] bool IsIdentifierStart(QChar c) {
  return c.isLetter() || c == QLatin1Char('_');
}
[[nodiscard]] bool IsIdentifierPart(QChar c) {
  return c.isLetterOrNumber() || c == QLatin1Char('_');
}
}  // namespace

Lexer::Lexer(QString file, QString source, Diagnostics& diagnostics)
    : file_(std::move(file)), source_(std::move(source)), diagnostics_(diagnostics) {}

QChar Lexer::Peek(int lookahead) const {
  const int pos = offset_ + lookahead;
  return pos >= 0 && pos < source_.size() ? source_.at(pos) : QChar();
}
bool Lexer::AtEnd() const { return offset_ >= source_.size(); }

void Lexer::Advance() {
  if (AtEnd()) return;
  if (source_.at(offset_) == QLatin1Char('\n')) {
    ++line_;
    column_ = 1;
  } else {
    ++column_;
  }
  ++offset_;
}

void Lexer::SkipWhitespaceAndComments() {
  for (;;) {
    while (!AtEnd() && Peek().isSpace()) Advance();
    if (Peek() == QLatin1Char('/') && Peek(1) == QLatin1Char('/')) {
      while (!AtEnd() && Peek() != QLatin1Char('\n')) Advance();
      continue;
    }
    if (Peek() == QLatin1Char('/') && Peek(1) == QLatin1Char('*')) {
      const SourceLocation start{line_, column_, offset_};
      Advance();
      Advance();
      while (!AtEnd() && !(Peek() == QLatin1Char('*') && Peek(1) == QLatin1Char('/'))) {
        Advance();
      }
      if (AtEnd()) {
        diagnostics_.Error(file_, start, QStringLiteral("unterminated block comment"));
        return;
      }
      Advance();
      Advance();
      continue;
    }
    break;
  }
}

Token Lexer::MakeToken(TokenKind kind, int start_offset, const SourceLocation& start) const {
  Token token;
  token.kind = kind;
  token.loc = start;
  token.text = source_.mid(start_offset, offset_ - start_offset);
  return token;
}

void Lexer::ScanPreprocessor() {
  const SourceLocation start{line_, column_, offset_};
  const int start_offset = offset_;
  // Stop before either newline character so CRLF input does not leak '\r'
  // into the token text; SkipWhitespaceAndComments() consumes the line ending.
  while (!AtEnd() && Peek() != QLatin1Char('\n') && Peek() != QLatin1Char('\r')) {
    Advance();
  }
  tokens_.push_back(MakeToken(TokenKind::Preprocessor, start_offset, start));
}

Token Lexer::ScanString() {
  const SourceLocation start{line_, column_, offset_};
  const int start_offset = offset_;
  Advance();  // opening quote
  QString value;
  while (!AtEnd() && Peek() != QLatin1Char('"') && Peek() != QLatin1Char('\n') &&
         Peek() != QLatin1Char('\r')) {
    if (Peek() == QLatin1Char('\\') && Peek(1) == QLatin1Char('"')) {
      value += QLatin1Char('"');
      Advance();
      Advance();
    } else if (Peek() == QLatin1Char('\\') && Peek(1) == QLatin1Char('\\')) {
      value += QLatin1Char('\\');
      Advance();
      Advance();
    } else {
      value += Peek();
      Advance();
    }
  }
  // Raw line endings inside a quoted string are errors. Leave the newline
  // unconsumed so the outer scan loop can treat it as ordinary whitespace and
  // keep lexing the rest of the file.
  if (AtEnd() || Peek() == QLatin1Char('\n') || Peek() == QLatin1Char('\r')) {
    diagnostics_.Error(file_, start, QStringLiteral("unterminated string literal"));
    Token token;
    token.kind = TokenKind::String;
    token.loc = start;
    token.text = value;
    return token;
  }
  Advance();  // closing quote
  Token token = MakeToken(TokenKind::String, start_offset, start);
  token.text = value;
  return token;
}

Token Lexer::ScanNumber() {
  const SourceLocation start{line_, column_, offset_};
  const int start_offset = offset_;
  if (Peek() == QLatin1Char('0') && (Peek(1) == QLatin1Char('x') || Peek(1) == QLatin1Char('X'))) {
    Advance();
    Advance();
    while (!AtEnd() && (Peek().isDigit() || (Peek().toLower() >= QLatin1Char('a') && Peek().toLower() <= QLatin1Char('f')))) Advance();
  } else {
    while (!AtEnd() && Peek().isDigit()) Advance();
  }
  return MakeToken(TokenKind::Number, start_offset, start);
}

Token Lexer::ScanIdentifier() {
  const SourceLocation start{line_, column_, offset_};
  const int start_offset = offset_;
  while (!AtEnd() && IsIdentifierPart(Peek())) Advance();
  return MakeToken(TokenKind::Identifier, start_offset, start);
}

QVector<Token> Lexer::Scan() {
  while (true) {
    SkipWhitespaceAndComments();
    if (AtEnd()) break;
    const QChar c = Peek();
    const SourceLocation start{line_, column_, offset_};
    const int start_offset = offset_;

    if (c == QLatin1Char('#')) {
      ScanPreprocessor();
    } else if (c == QLatin1Char('"')) {
      tokens_.push_back(ScanString());
    } else if (c.isDigit()) {
      tokens_.push_back(ScanNumber());
    } else if (IsIdentifierStart(c)) {
      tokens_.push_back(ScanIdentifier());
    } else if (c == QLatin1Char('{')) {
      Advance(); tokens_.push_back(MakeToken(TokenKind::LBrace, start_offset, start));
    } else if (c == QLatin1Char('}')) {
      Advance(); tokens_.push_back(MakeToken(TokenKind::RBrace, start_offset, start));
    } else if (c == QLatin1Char('(')) {
      Advance(); tokens_.push_back(MakeToken(TokenKind::LParen, start_offset, start));
    } else if (c == QLatin1Char(')')) {
      Advance(); tokens_.push_back(MakeToken(TokenKind::RParen, start_offset, start));
    } else if (c == QLatin1Char('<')) {
      Advance(); tokens_.push_back(MakeToken(TokenKind::Less, start_offset, start));
    } else if (c == QLatin1Char('>')) {
      Advance(); tokens_.push_back(MakeToken(TokenKind::Greater, start_offset, start));
    } else if (c == QLatin1Char(',')) {
      Advance(); tokens_.push_back(MakeToken(TokenKind::Comma, start_offset, start));
    } else if (c == QLatin1Char(';')) {
      Advance(); tokens_.push_back(MakeToken(TokenKind::Semicolon, start_offset, start));
    } else if (c == QLatin1Char('=')) {
      Advance(); tokens_.push_back(MakeToken(TokenKind::Equals, start_offset, start));
    } else if (c == QLatin1Char('&')) {
      Advance(); tokens_.push_back(MakeToken(TokenKind::Ampersand, start_offset, start));
    } else if (c == QLatin1Char('*')) {
      Advance(); tokens_.push_back(MakeToken(TokenKind::Star, start_offset, start));
    } else if (c == QLatin1Char('-')) {
      Advance(); tokens_.push_back(MakeToken(TokenKind::Minus, start_offset, start));
    } else if (c == QLatin1Char(':') && Peek(1) == QLatin1Char(':')) {
      Advance(); Advance(); tokens_.push_back(MakeToken(TokenKind::ColonColon, start_offset, start));
    } else {
      diagnostics_.Error(file_, start, QStringLiteral("unexpected character '%1'").arg(c));
      Advance();
    }
  }

  Token end;
  end.kind = TokenKind::End;
  end.loc = SourceLocation{line_, column_, offset_};
  tokens_.push_back(end);
  return tokens_;
}

}  // namespace ddsrpcgen
```

  - 默认表达式必须使用原始源码区间并 `trimmed()` 保留 C++ 片段；不能使用 `token.loc.offset + token.text.size()`，因为 String token 的 `text` 已去掉引号并折叠转义。用下一个 token 的起始 offset（或 Token 增加源码 end offset）作为切片边界，并加字符串默认值回归测试。
  - `PROP(QString label = "a b")` 的默认值必须保留为 `"a b"`，`PROP(QString quoted = "a\"b")` 必须保留转义，不得解码后生成非法 C++。
  - `PERSISTED` 写入 `persisted=true`，后续语义层拒绝。
- `ParseSignal`：
  - 在 `SIGNAL(` 后读取 name，然后是 `(` 参数列表 `)`；返回类型不允许。
- `ParseSlot`：
  - 在 `SLOT(` 后收集到参数左括号前的 token；最后一个标识符是函数名，前面的 token 用 `ParseTypeFromSlice` 解析为返回类型；空返回类型则是 `void`。
- `ParseParams`：
  - 空括号返回空 vector；否则循环 `ParseType` + 可选 name；逗号分隔；未命名参数 `name` 为空。
- `ParseType` 支持：
  - 前缀 `const`；
  - `unsigned/signed/long/short` 等限定词可连续消费，再消费基础标识符；
  - 限定名 `::`；
  - 模板参数递归；
  - 末尾 `&`（`&&` 也折叠为引用）；
  - 遇到 `*` 报错。
- `Parse()` 的 class 分支替换为 `ParseClass()`。
- 在 class 内看到 `MODEL/CLASS/FLAG/USE_ENUM` 时产生定向错误；解析器不继续冒险。
- `PERSISTED` 的拒绝放在语义层，保证 parser 测试中仍有诊断（parser 可以立即报不支持；二者任一位置均可，但错误必须非空）。

`task_group.h`：

```cpp
#pragma once
#include <cstdint>
#include <functional>
#include <memory>

#include "await/awaitable.hpp"
#include "task/fibertask.h"
#include "detail/result.hpp"

namespace ddsrpc {

class TaskGroup {
 public:
  TaskGroup() = default;
  ~TaskGroup();
  TaskGroup(const TaskGroup&) = delete;
  TaskGroup& operator=(const TaskGroup&) = delete;

  void Start();
  bool Add(std::function<void()> fn);
  [[nodiscard]] Coro::Result<void> Stop();

 private:
  struct State;
  void ReapLoop();

  std::shared_ptr<State> state_;
  std::shared_ptr<Coro::FiberTask<void>> reaper_;
  std::uint64_t next_id_ = 1;
  bool started_ = false;
};

}  // namespace ddsrpc
```

实现：
- `State` 保存 `std::map<uint64_t, std::shared_ptr<Coro::FiberTask<void>>> tasks`、`std::shared_ptr<Coro::Awaitable<uint64_t>> completed`、`bool stopping`。
- `Start`: 创建 state/completed，并调用 `completed->setCapacity(0)` 取消完成通知队列的 1024 条上限（服务端请求并发无框架上限）；启动 reaper `Coro::makeTask([this]{ReapLoop();}, Priority::Normal, Affinity::fixed(std::this_thread::get_id()))`。
- `Add`:
  - 若 `!started_` 或 `state_->stopping` 返回 false。
  - 捕获 `auto channel = state_->completed->channel();`。
  - 创建 `std::shared_ptr<FiberTask<void>>` 运行 `fn`，捕获异常，末尾 `channel->push(id)`。
  - 插入 `state_->tasks`。
- `ReapLoop`: `while (auto id = Coro::await(state_->completed)) { state_->tasks.erase(id.value()); }`。
- `Stop`:
  - `state_->stopping = true`；把 tasks 移入局部 vector 并清空 map。
  - 对每个 `task->cancel()`，然后 `(void)task->get()`。
  - 关闭 `state_->completed`，join reaper。
  - `started_=false`；返回成功。
- 任务函数不得在完成后调用 `get()`；reaper 只销毁句柄。
- `Add`/`Stop` 必须在同一 fiber 执行域调用。

实现：
- `Prepare`: RegisterClients + RegisterSubscribers；失败回滚；`prepared_=true`。
- `StartEvents`: 订阅 event topic（`Subscribe({event_topic}, {MessageKind::kNotify})`），启动 EventLoop task。
- `StopEvents`: 关闭事件 Ticket mailbox；cancel/join event task；重置。
- `EventLoop`:
  - `for(;;)`: `events_->Wait()`; if error break.
  - Parse QDataStream on msg.payload; `wire::Begin`; `ReadEventHeader`; validate schema; if mismatch set error/emit syncFailed and break.
  - Signal -> DispatchSignal; Property -> DispatchProperty.
  - Catch exceptions and continue/break on decode error.
- `CallWithRetry`:
  - Build args payload: QByteArray buffer; QDataStream out; wire::Begin; WriteRequestHeader; append args.
  - Message req; endpoint Service(service_name); `RequestForResultDirect(req, retry)`.
  - Parse reply header; validate schema; if !ok ReadError; set last error text; return error code. Success return reply payload after header. 
  - On transport error, return it unchanged.
- `Call` delegates with `request_retry`.
- `HandleLinkState(transport::LinkState state)`:
  - If state != Up:
    - if link_up_: link_up_=false; sync_blocked_=false; SetReady(false).
    - return success.
  - If state == Up and !link_up_:
    - `sync_blocked_=false`;
    - `RenewEvents()`；成功后 `link_up_=true`；失败时保持 `link_up_=false` 并返回错误，下一次链路轮询重试。
    - `SetReady(false)`；`ResetPropertiesForResync()`。
  - If !ready and !sync_blocked_: `return SyncOnce();`
  - return success.
- `SyncOnce`:
  - `CallWithRetry(0, {}, RetryPolicy{500ms, 1})`.
  - On success: QDataStream payload; `ApplyPropertySnapshot`; SetReady(true).
  - On schema/protocol error: SetLastErrorText, sync_blocked_=true, EmitSyncFailed; SetReady(false); return error.
  - On transport timeout/closed: SetReady(false); return error (not blocked).
- `refreshProperties`:
  - 清 `sync_blocked_`，调用 `ResetPropertiesForResync()`，再 `CallWithRetry(0, {}, RetryPolicy{500ms, 1})` 并应用快照；成功置 ready，失败按错误返回。
  - It should be a coroutine; caller invokes within fiber.
- `RenewEvents`: StopEvents (if any), StartEvents.
- `StopEndpoint`: StopEvents; SetReady(false); `link_up_=false`; `sync_blocked_=false`。
- `SetReady` emits `EmitReadyChanged` only on change.
- `SetLastErrorText` locks mutex.
- Link monitor is generated, not base. `HandleLinkState` is called from generated code.

```cmake
function(ddsrpc_scan_idl_imports file include_dirs out_files')
  if(ARGC GREATER 3)
    set(stack ${ARGV3})
  else()
    set(stack "")
  endif()
  get_filename_component(file_abs "${file}" ABSOLUTE)
  if(NOT EXISTS "${file_abs}")
    message(FATAL_ERROR "IDL not found: ${file_abs}")
  endif()
  if(file_abs IN_LIST stack)
    string(JOIN " -> " chain ${stack} "${file_abs}")
    message(FATAL_ERROR "IMPORT cycle: ${chain}")
  endif()
  list(APPEND stack "${file_abs}")
  file(READ "${file_abs}" content)
  string(REGEX REPLACE "//[^\n]*" "" content "${content}")
  string(REGEX MATCHALL "IMPORT[ \t]+\"([^\"]+)\"" import_lines "${content}")
  set(result "${file_abs}")
  foreach(line IN LISTS import_lines)
    string(REGEX REPLACE "IMPORT[ \t]+\"([^\"]+)\"" "\\1" import_name "${line}")
    get_filename_component(import_dir "${file_abs}" DIRECTORY)
    set(candidates "${import_dir}/${import_name}")
    foreach(dir IN LISTS include_dirs)
      list(APPEND candidates "${dir}/${import_name}")
    endforeach()
    set(found "")
    foreach(candidate IN LISTS candidates)
      if(EXISTS "${candidate}")
        get_filename_component(candidate_abs "${candidate}" ABSOLUTE)
        set(found "${candidate_abs}")
        break()
      endif()
    endforeach()
    if(found STREQUAL "")
      message(FATAL_ERROR "IMPORT not found: ${import_name} (from ${file_abs})")
    endif()
    set(child_files "")
    ddsrpc_scan_idl_imports("${found}" "${include_dirs}" child_files "${stack}")
    list(APPEND result ${child_files})
  endforeach()
  list(REMOVE_DUPLICATES result)
  set(${out_files'} "${result}" PARENT_SCOPE)
endfunction()
```

```cmake
include(CMakeParseArguments)
include("${CMAKE_CURRENT_LIST_DIR}/ScanIdlImports.cmake")

function(ddsrpc_add_idl target)
  set(options)
  set(one_value_args NAMESPACE)
  set(multi_value_args ROLES IDL INCLUDE_DIRS)
  cmake_parse_arguments(DDSRPC "${options}" "${one_value_args}" "${multi_value_args}" ${ARGN})
  if(NOT DDSRPC_IDL)
    message(FATAL_ERROR "ddsrpc_add_idl(${target}) requires IDL")
  endif()
  if(NOT DDSRPC_ROLES)
    set(DDSRPC_ROLES service)
  endif()
  set(scan_include_dirs "")
  foreach(dir IN LISTS DDSRPC_INCLUDE_DIRS)
    get_filename_component(dir_abs "${dir}" ABSOLUTE)
    list(APPEND scan_include_dirs "${dir_abs}")
  endforeach()
  set(all_files "")
  set(root_abs_args "")
  foreach(root IN LISTS DDSRPC_IDL)
    get_filename_component(root_abs "${root}" ABSOLUTE)
    list(APPEND root_abs_args "${root_abs}")
    set(scanned "")
    ddsrpc_scan_idl_imports("${root_abs}" "${scan_include_dirs}" scanned)
    list(APPEND all_files ${scanned})
  endforeach()
  list(REMOVE_DUPLICATES all_files)
  set(gen_dir "${CMAKE_CURRENT_BINARY_DIR}/ddsrpc/${target}")
  set(outputs "")
  set(seen_stems "")
  foreach(idl IN LISTS all_files)
    get_filename_component(stem "${idl}" NAME_WE)
    if(stem IN_LIST seen_stems)
      message(FATAL_ERROR "Duplicate IDL stem '${stem}' in ${target}")
    endif()
    list(APPEND seen_stems "${stem}")
    list(APPEND outputs "${gen_dir}/${stem}.ddsrpc.types.h")
    list(FIND DDSRPC_ROLES "service" service_index)
    if(service_index GREATER -1)
      list(APPEND outputs
        "${gen_dir}/${stem}.ddsrpc.service.h"
        "${gen_dir}/${stem}.ddsrpc.service.cpp")
    endif()
    list(FIND DDSRPC_ROLES "client" client_index)
    if(client_index GREATER -1)
      list(APPEND outputs
        "${gen_dir}/${stem}.ddsrpc.client.h"
        "${gen_dir}/${stem}.ddsrpc.client.cpp")
    endif()
  endforeach()

  string(REPLACE ";" "_" role_tag "${DDSRPC_ROLES}")
  set(depfile "${gen_dir}/ddsrpc-${role_tag}.d")
  set(role_arg "all")
  list(LENGTH DDSRPC_ROLES role_count)
  if(role_count EQUAL 1)
    set(role_arg "${DDSRPC_ROLES}")
  endif()
  set(ns_args "")
  if(DEFINED DDSRPC_NAMESPACE AND NOT DDSRPC_NAMESPACE STREQUAL "")
    set(ns_args --namespace "${DDSRPC_NAMESPACE}")
  endif()
  set(include_args "")
  foreach(dir IN LISTS DDSRPC_INCLUDE_DIRS)
    get_filename_component(dir_abs "${dir}" ABSOLUTE)
    list(APPEND include_args -I "${dir_abs}")
  endforeach()

  add_custom_command(
    OUTPUT ${outputs}
    COMMAND ${CMAKE_COMMAND} -E make_directory "${gen_dir}"
    COMMAND $<TARGET_FILE:ddsrpcgen>
            --role "${role_arg}"
            --out-dir "${gen_dir}"
            ${ns_args}
            ${include_args}
            --depfile "${depfile}"
            ${root_abs_args}
    DEPENDS ddsrpcgen ${all_files}
    DEPFILE "${depfile}"
    COMMENT "Generating ddsrpc code for ${target}"
    VERBATIM)

  target_sources(${target} PRIVATE ${outputs})
  target_include_directories(${target} PRIVATE "${gen_dir}")
  target_link_libraries(${target} PUBLIC ddsrpc::runtime)
  set_target_properties(${target} PROPERTIES AUTOMOC ON)
endfunction()
```

```cpp
#include <QCoreApplication>
#include <QObject>

#include <atomic>
#include <chrono>
#include <functional>
#include <iostream>
#include <memory>
#include <string>

#include <QUuid>
#include <boost/fiber/operations.hpp>

#include "detail/asyncdefine.h"
#include "hello.ddsrpc.client.h"
#include "hello.ddsrpc.service.h"
#include "task/fiberapplication.h"
#include "task/fibertask.h"
#include "transport/codec/DdsCodec.hpp"
#include "transport/io/dds/DdsConfig.hpp"
#include "transport/io/dds/DdsProviderRegistry.hpp"
#include "transport/io/dds/DdsTransport.hpp"
#include "transport/node/DdsNode.hpp"

namespace {

bool PumpUntil(const std::function<bool()>& predicate, int budget_ms = 5000) {
  for (int waited = 0; waited < budget_ms; waited += 5) {
    if (predicate()) return true;
    boost::this_fiber::sleep_for(std::chrono::milliseconds(5));
  }
  return predicate();
}

class GreeterImpl final : public demo::GreeterService {
 public:
  using GreeterService::GreeterService;

 protected:
  Coro::Result<QString> greet(QString name) override {
    auto published = publishAnnounced(1);
    if (!published) return published.error();
    return QStringLiteral("hello ") + name;
  }
  Coro::Result<void> reset() override { return {}; }
};

}  // namespace

int main(int argc, char** argv) {
  QCoreApplication app(argc, argv);
  Coro::installFiberApplication();
  int exit_code = 1;

  auto task = Coro::makeTask([&] {
    const QString provider = QStringLiteral("hello-%1")
                                 .arg(QUuid::createUuid().toString(QUuid::WithoutBraces));
    auto bus = std::make_shared<transport::FakeDdsProvider::Bus>();
    transport::DdsProviderRegistry::RegisterProvider(
        provider.toStdString(), [bus] {
          return std::unique_ptr<transport::IDdsProvider>(
              new transport::FakeDdsProvider(bus));
        });

    transport::DdsConfig config;
    config.provider = provider.toStdString();
    transport::DdsTransport server_transport(config);
    transport::DdsTransport client_transport(config);
    if (!server_transport.Start() || !client_transport.Start()) {
      std::cerr << "transport start failed
";
      Coro::quit();
      return;
    }

    transport::DdsNode server_node(server_transport,
                                   std::make_unique<transport::DdsCodec>());
    transport::DdsNode client_node(client_transport,
                                   std::make_unique<transport::DdsCodec>());
    GreeterImpl service(server_node);
    demo::GreeterClient client(client_node, client_transport);

    if (!service.prepare() || !client.prepare() ||
        !server_node.Start() || !client_node.Start() || !client.start()) {
      std::cerr << "endpoint start failed
";
      Coro::quit();
      return;
    }

    Coro::msleep(100);
    const bool ready_before = client.ready();
    if (!service.start()) {
      std::cerr << "service start failed
";
      Coro::quit();
      return;
    }
    const bool ready_after = PumpUntil([&] { return client.ready(); });
    std::atomic_int count{-1};
    std::atomic_int announced{0};
    QObject::connect(&client, &demo::GreeterClient::countChanged,
                     [&count](int value) { count.store(value); });
    QObject::connect(&client, &demo::GreeterClient::announced,
                     [&announced](int value) { announced.store(value); });
    const auto greeting = client.greet(QStringLiteral("demo"));
    if (!greeting || !service.setCount(1) ||
        !PumpUntil([&] { return count.load() == 1 && announced.load() == 1; })) {
      std::cerr << "rpc/property/signal flow failed
";
      Coro::quit();
      return;
    }

    std::cout << "ready-before-service=" << (ready_before ? 1 : 0) << "
";
    std::cout << "ready-after-service=" << (ready_after ? 1 : 0) << "
";
    std::cout << "greet=" << greeting.value().toStdString() << "
";
    std::cout << "count=" << count.load() << "
";
    std::cout << "announced=" << announced.load() << "
";
    exit_code = 0;

    (void)client.stop();
    (void)service.stop();
    client_node.Close();
    client_node.WaitClosed();
    server_node.Close();
    server_node.WaitClosed();
    (void)client_transport.Close();
    client_transport.WaitClosed();
    (void)server_transport.Close();
    server_transport.WaitClosed();
    Coro::quit();
  });

  Coro::exec();
  (void)task;
  return exit_code;
}
```

````markdown
## 生命周期

transport.Start() → node 创建 → endpoint.prepare() → node.Start() →
service.start() / client.start() → ... → stop() → node.Close() →
transport.Close()。

Client 的 `prepare/start` 不等待服务；`start()` 立即返回，后台链路监控在
DdsTransport LinkState 变为 Up 后完成 schema 握手/属性快照。重连后自动重新订阅并刷新 PROP。
客户端信号在节点执行线程发射；跨线程 Qt 连接自动排队。

客户端上行只能调用生成的 SLOT；客户端不是事件 publisher。

## 限制

- 仅支持 RPC 子集；MODEL/CLASS/FLAG/USE_ENUM/PERSISTED 不支持。
- 双端必须由同一生成器生成；载荷为 QDataStream，不是标准 DDS CDR。
````
